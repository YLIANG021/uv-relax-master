# 👉 UV Relax Master 👈

### 专注于 UV 松弛的工具，让 UV 分布更均匀、结果更容易检查、局部修复更可控

无论是整个 UV 岛、局部选区，还是横向与纵向的点列，都可以快速进行松弛。它适合处理已经完成展开、但局部点位不均匀或拉伸不理想的 UV，尤其适合需要保留边界和周围结构的修复工作。

## 它能做什么

- 🧠 **更好的松弛算法**：针对 UV 分布进行更细致的均匀化处理，减少不必要的拉伸和挤压，让结果更加平滑、稳定。
- 🎨 **直观的拉伸显示**：用不同颜色区分过度拉伸、过度压缩和接近正常的区域，帮助你快速判断 UV 哪里需要继续调整。
- 🧩 **多种松弛方式**：支持整体松弛、局部松弛、横向松弛和纵向松弛。已经固定好边界的 UV，也可以只修复内部区域。
- 🎯  **灵活选点与快速对齐 **：一键选中 UV 岛的内部点或边界点，再向上、下、左、右对齐，既为局部松弛备好选区，也顺手把不齐的边缘和点列整理整齐。
## 如何使用

进入 **UV 编辑器**，打开右侧的侧栏，就能找到 **UV Relax Master** 面板。

支持语言：英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、意大利语、波兰语、葡萄牙语、俄语、越南语。

## 1. 更均匀的松弛算法

UV Relax Master 专注于让 UV 分布更加均匀。在减少拉伸的同时尽量保持原有形状和结构，适合用来改善自带松弛工具处理后仍然不够均匀的区域。



![1](图片占位符_1)



## 2. 直观看出 UV 拉伸与压缩

开启后，通过颜色直观看出松弛结果,过度密集用红色，过度松弛用蓝色，正常的区域用灰色，比默认显示更直观，一眼就能看出哪里有问题。



![2](图片占位符_2)



## 3. 局部、横向与纵向松弛

除了整体松弛，你还能用局部松弛用于只修复选中的区域，横向松弛和纵向松弛则用于整理单一方向上的点位分布。

对于已经固定好边界的 UV，这个功能尤其有用：选中需要修复的内部点，就可以在尽量保持边界的情况下改善内部密度



![3](图片占位符_3)



## 4. 快速对齐与打直

选中需要整理的 UV 点后，可以快速向上、下、左或右对齐。用于快速提供规则UV边界,然后再进行后期松弛。



![4](图片占位符_4)



## 5. 选择内部点与边界点

通过选择功能，可以快速选中 UV 岛的内部点或边界点。配合局部松弛使用时，可以更快地限定处理范围，减少对已经调整好的区域造成影响。



![5](图片占位符_5)

## 🧩 适合什么场景

UV 已经展开完成，但局部点位分布不均、边缘不齐、某个方向上出现拉伸或压缩时，可以先固定好需要保留的边界，再选择内部区域进行局部松弛。显示叠加可以帮助你在操作前后检查结果。
